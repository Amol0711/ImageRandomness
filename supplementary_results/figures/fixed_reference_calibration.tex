\caption*{Spatial conditioning in blocked average changing intensity (BACI) with overlapping $2\times2$ windows, a fixed reference image and $q=256$. Here $B$ denotes the normalized BACI statistic. (a) Five deterministic $256\times256$ reference patterns on a common intensity scale. Checker shows an enlarged $8\times8$ pixel crop; the other thumbnails represent the full images. (b) Rejection at nominal 5\% over 5000 independent comparison images per pattern, with mutually independent uniform pixels. Pair indep.\ denotes the Gaussian rule using the pair-occurrence independence approximation~\cite{zhang2021}, which treats every pair occurrence as independent. Within-window denotes the within-window covariance diagnostic. Full covariance denotes the full-covariance Gaussian rule. Error bars are Wilson 95\% intervals, conditional on the realized independent bank of $L=9999$ reference statistics for the independent-null rank rule. Panels~(c,d) display exact $\E[100B]$ and $\Var(100B)$, respectively, for Checker and Split. The mean is expressed as a percentage and the variance in squared percentage points. These patterns have identical histograms, and the checkerboard variance is 2.32180 times the split variance. The moment panels contain deterministic calculations.}
